# ID Reminder

A Flutter Android app that reminds users to carry their ID cards, supports OCR and NFC card verification, schedules alarms, and only stops alerts after the correct card is scanned.

## Features

- OCR-based school ID registration
- NFC-only card registration and NFC linking
- Multiple saved ID cards
- Reminder creation, editing, deletion, and repeat scheduling
- Alarm verification gate with OCR or NFC scan-to-stop behavior
- Local storage using SharedPreferences
- Android notification, exact alarm, full-screen alarm, vibration, and NFC support

## Run

```bash
flutter pub get
flutter run
```
